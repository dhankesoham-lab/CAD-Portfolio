CAD & Mechanical Design Portfolio

This repository documents 3D CAD modeling, kinematic assemblies, and technical blueprint drafting created using **SolidWorks**.

---

Repository Structure

* **`Rubiks_Mechanism/`**: Multi-component parametric assembly of an interlocking rotating mechanism optimized with radial clearances for FDM 3D printing.
* **`Vehicle_Assembly/`**: Motorized chassis and guide-track sub-assembly featuring multi-link bars, dampers, motor brackets, and standard metric hardware (M1.5–M4).
* **`Parts/`**: Collection of 20+ complex mechanical components modeled directly from 2D engineering projection blueprints using advanced lofts, sweeps, and sheet metal features.

---

Tools & Capabilities
* **Software:** SolidWorks (Part Modeling, Assemblies, Sheet Metal, 2D Drafting)
* **Manufacturing Focus:** Design for 3D Printing (FDM), Rapid 2D-to-3D Blueprints, Tolerance & Clearance Fits
